# ExamSeat

A simple project to help manage and assign exam seating arrangements.

## Description

This repository contains code and resources for generating and managing exam seating plans. It can be used to assign seats to students, export seating charts, and reduce conflicts during examinations.

## Features

- Assign seats to students
- Export seating charts
- Simple configuration
